# Handoff: Queen's Domain Lab

Paste this whole file into a new chat to continue work. Read `README.md` and `docs/ARCHITECTURE.md` first.

## What it is
A Windows desktop app (Edge `--app` window + a local Node helper) in a StarCraft 1 / Protoss style. It turns a questionnaire into a step-by-step plan of AI prompts for building a game, audits AI output with a chosen model, and rates free local models against this PC.

## Layout
`app/` (index.html, wizard.js, icon.png) · `server/server.js` · `scripts/` (install.ps1, launcher.ps1) · `tests/run.js` · `docs/` · `AGENTS.md` · `CLAUDE.md`

## Current state
- **Chat (home screen)**: provider/model/effort picker, streamed replies (HTTP providers; CLIs return in one piece), Stop, Retry, saved chats in the sidebar, project context, size meter, Compare with a second model, Save .md, next-model suggestion on limit errors. See `docs/DESIGN.md`.
- **Layout**: left sidebar (New chat, tabs, recent chats, projects). The old Projects tab is now **Design** (New profile / Continue / Duplicate).
- **Projects**: Queen's Domain preset (50 fixed steps) + custom projects from a 25-question wizard (10 platforms, 10 genres, 5 GameDiscover sub-genres, cameras, art, size, multiplayer, story, difficulty, accessibility, budget, ...). Step count is dynamic (9 / 21 / 25 / 30+).
- **Briefing**: copy prompts, mark complete, audit, **Edit profile** (progress kept by step title), **Copy plan / Save .md** export, hardware verdict line.
- **Settings**: detects Claude Code, Codex, Kimi, Ollama, LM Studio, Gemini CLI, OpenRouter, Gemini API. Claude/Codex use their own sign-ins with a Log in button and status bar. Quiet activity log + Copy log.
- **Local models**: 26 Ollama models rated green/yellow/orange/red for this PC, hover cards (0.5 s spinner), "BEST FOR YOU" badge (`qwen2.5-coder:7b`), first-time setup guide, Benchmark button, disk check.
- **Auditor**: runs on the loaded model via `POST /api/run`. Preset uses its own 12 rules; custom projects use `rulesFor()`.
- Tests: `npm test` (17 checks, all passing).

## Gotchas
- `wizard.js` and the inline script share one global scope: model picker is `pick`, wizard helper is `pickOpt`. Don't collide (`P`, `el`, `info`, `LVL`).
- Restart `server/server.js` after editing it (stale process = stale code).
- Test with `npm test`; UI via `npm start` + the browser pane at http://127.0.0.1:47831/.

## Preferences
